# GameProject

Unity project for the team to develop together.

## Open the project

1. Install Unity **6000.3.25f1** through Unity Hub.
2. Clone this repository.
3. In Unity Hub, choose **Add > Add project from disk** and select the cloned project folder.
4. Let Unity finish importing packages and assets before opening a scene.

The placeholder menu scene is `Assets/Scenes/MainMenuTest.unity`.

## Collaboration notes

- Keep each asset's `.meta` file with the asset.
- Commit changes to `Assets`, `Packages`, and `ProjectSettings` when they are part of the work.
- Do not commit Unity's generated `Library`, `Temp`, `Logs`, or `UserSettings` folders; Git ignores them.
